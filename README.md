# Customer-Churn-Analysis

Customer churn analysis project with a Streamlit dashboard and an exploratory
Jupyter notebook.

#StreamLit Deployed App Link

https://customer-churn-analysis-nmys9zgpcw8dcfrgnaibdq.streamlit.app/

## Project files

- `app.py` — Streamlit dashboard
- `data/WA_Fn-UseC_-Telco-Customer-Churn.csv` — customer churn dataset
- `notebooks/customer_churn_analysis.ipynb` — analysis notebook

## Run the dashboard

```powershell
python -m pip install -r Requirements.txt
streamlit run app.py
```
